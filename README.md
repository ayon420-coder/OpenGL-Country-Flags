# OpenGL Country Flags

A Computer Graphics project developed using C++ and OpenGL/GLUT to draw
different national flags using geometric primitives.

## Project Overview

This project demonstrates how country flags can be created programmatically
using Computer Graphics concepts such as:

- OpenGL
- GLUT
- 2D geometric primitives
- Lines
- Rectangles
- Circles
- Polygons
- Transformations
- Colors
- Coordinate systems

Each flag is constructed using C++ code rather than imported image files.

## Countries Included

| No. | Country | Key Graphics Concepts |

| 4 | Ghana | Rectangle, Circle |
